# React Scroll Picker Component

A modern, customizable scroll picker component made with React and TypeScript. Perfect for date and time selection with smooth scrolling  and mobile touch support.

## 🚀 Features

- **Infinite Scroll**: Smooth infinite scrolling for date, hours, and minutes
- **Touch Support**: Full mobile device support with swipe gestures
- **Responsive Design**: Adapts perfectly to mobile and desktop screens
- **URL Integration**: Syncs selected values with URL query parameters
- **TypeScript**: Full TypeScript support with type safety
- **3D Effects**: Beautiful visual effects with scaling and perspective
- **Customizable**: Easy to customize styles and behavior

## 📱 Demo

The component displays a 4-column picker:

1. **Date** - Scrollable date selection with "Today" highlight
2. **Hours** - 12-hour format (1-12)
3. **Minutes** - 5-minute intervals (00, 05, 10, etc.)
4. **AM/PM** - Period selection

## 🛠 Installation

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

### Local Setup

1. **Clone the repository**

   ```bash
   git clone https://github.com/maksym-kostetskyi/scroll-picker.git
   cd scroll-picker
   ```

2. **Install dependencies**

   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start development server**

   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open in browser**
   ```
   http://localhost:[port]
   ```
